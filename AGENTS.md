# Instructions for any coding agent working in this repo or a project made from it

(Codex reads this file. `CLAUDE.md` points here.)

1. Read `brand/brand.json` if it exists. If not, run the brand interview in `brand/BRAND-INTERVIEW.md` before any design work.
2. Read `docs/WORKFLOW.md` and the skill for the task in `skills/`. Load `skills/fable-mode/SKILL.md` for any multi-step build, video or motion brief, or after a failed attempt.
3. Roles: see `docs/MODEL-ROLES.md`. Plan first, build second, review third.
4. Hard stops, always ask the user first: installs, downloads, logins, uploads, publishing, paid services, deleting files.
5. Never put secrets, tokens or personal data in files, commits or chat. Never commit `brand/brand.json`, logos, footage or renders.
6. Report evidence, not claims: what you ran, what you saw, what you did not check.
