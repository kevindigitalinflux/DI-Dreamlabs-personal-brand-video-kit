# Pack: video, motion graphics and visual work from references

For any video in this kit, load the `pb-video-style` skill first; its style system and gate are authoritative and this pack only adds planning habits.

Earlier builds looked unprofessional despite direct reference videos, because "make it like this" was passed on as words. The build the user called "exactly what I wanted" was made in stages, each shown to them as a small artefact, with their replies recorded verbatim.

## Turn references into measurements

Never brief with adjectives ("clean", "premium", "dynamic"). For each reference, extract frames and write down:

- Layout: frame size, safe margins, where the presenter sits, how much of the frame an overlay covers.
- Type: font, weight, size as a fraction of frame height, line length, colour values, case.
- Motion: what moves, duration in frames, easing, what it is synchronised to (a spoken word, a cut).
- Rhythm: how often something changes on screen, longest stretch with no change.
- What is absent: no music, no stock clip-art, no drop shadows. Absences define a style as much as presences.

State which frames you inspected. Never claim to have watched or listened to a video.

## Plan in gates

1. Words and cuts, shown as a list the user can mark.
2. Audio decisions, as short A/B clips.
3. Still images or style frames for each new visual idea.
4. One short scene built fully, before the rest.
5. Full build, then the final render.

Each gate is a small artefact and a stop. Record the user's reply word for word. "Looks pretty good" with notes is a change list, not approval to render.

## Acceptance

- Side-by-side stills: reference frame next to our frame, for each visual idea.
- Every effect tied to its spoken word from a timing file, with a tolerance in frames.
- Automated checks pass before any render, and the number of full renders is capped.
- A list of what was not inspected.
